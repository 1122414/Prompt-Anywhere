# 浊心斯卡蒂 · 三形态主题包

这是一个可移植的横向桌面主题包，包含三个可切换形态：

- `abyssal-omen`：深海异兆
- `crimson-coronation`：血月冠冕
- `serene-tide`：静海归潮

所有背景均为 16:9 全幅 PNG，人物主视觉位于右侧，左侧保留低细节安全区，便于覆盖导航、搜索框、说明文字或半透明面板。`manifest.json` 同时提供每个形态的配色覆盖值。

复用方式：

1. 复制整个 `corrupting-heart-skadi` 目录。
2. 读取 `manifest.json`，使用 `default_variant` 作为初始形态。
3. 根据用户选择加载 `variants[].background`。
4. 先应用 `base_palette`，再用当前形态的 `palette` 覆盖同名颜色。
5. 把用户选择的形态 `id` 保存到目标项目的偏好设置。
